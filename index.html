This tab is your host screen and stays on the laptop. It shows every answer. The TV gets its own tab that only shows answers after you reveal them. Everything saves automatically, so a refresh won't wipe the scores.

Pick a game

TV setup

  1. Plug in the TV and set the display to Extend, not mirror. (Windows: Win + P → Extend. Mac: System Settings → Displays → set the TV as an extended display.)
  2. Click 📺 Open TV screen. Drag that new tab out of this window and onto the TV.
  3. Click once anywhere on the TV screen to make it fullscreen.
  4. Come back to this tab on the laptop and run the game from here.

Button didn't open a tab? Open this same file in a new tab yourself and add #tv to the end of the address.

Main rounds

One round per block, with a blank line between rounds. First line is the question. Add x2 or x3 at the end of the question for double or triple points. Then one answer per line with its points at the end, like Turkey 36. Up to 8 answers, auto-sorted by points. The built-in point values are made up, so tweak away.

Fast Money

Same format, 5 questions, up to 8 answers each. The answers show up as quick-pick buttons on your host screen during Fast Money, so more answers means fewer "is that on the list?" moments.
